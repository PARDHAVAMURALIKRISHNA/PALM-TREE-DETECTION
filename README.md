# PALM-TREE-DETECTION
# Palm Tree Detection using Deep Learning

## Overview
This project focuses on detecting and counting palm trees from aerial images using the YOLOv8 object detection model. The system is designed for agricultural monitoring, environmental analysis, and drone-based surveillance applications.

---

## Tech Stack
- Python
- YOLOv8
- Ultralytics
- Roboflow
- OpenCV
- Matplotlib
- NumPy

---

## Features
- Real-time palm tree detection
- Object detection using YOLOv8
- Aerial image analysis
- Palm tree counting system
- Precision-recall evaluation
- Drone surveillance support

---

## Dataset
- Custom annotated aerial image dataset
- 800+ labeled images
- Annotation performed using Roboflow

---

## Project Workflow
1. Dataset collection and annotation
2. Image preprocessing
3. YOLOv8 model training
4. Validation and testing
5. Object detection and counting
6. Performance evaluation

---

## Model Architecture
- YOLOv8 object detection model
- Bounding box prediction
- Real-time inference capability

---

## Evaluation Metrics
The model performance was evaluated using:
- Precision
- Recall
- mAP (Mean Average Precision)
- Confusion Matrix

---

## Results
- Achieved 89.5% mAP50 using YOLOv8
- Precision: 85.7%
- Recall: 87.4%
- Efficient real-time palm tree detection from aerial imagery
- Reliable object localization and counting performance
